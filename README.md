# College Bus Pass Management System

This project is an online digital solution for managing college bus passes, designed to address a common issue faced by students, including myself, during our academic journey.

## 📚 Project Overview

In the third year of our academic curriculum, we were tasked with a mini-project. As a team, we decided to focus on solving a real-world problem that directly affected us — managing physical college bus passes. These passes, issued to students who have paid the bus fee, often posed challenges:

- If a student forgot their physical card, they faced inconvenience or trouble.
- There was no digital alternative to verify a student’s bus pass on the spot.

To resolve this, we created an **Online Digital College Bus Pass** system. This project allows students to:

- **Register online** for the college bus service.
- **Generate and download a digital bus pass** after fee payment.
- **Present the digital pass on their phone** as a valid substitute for the physical card.

Our goal was to make the process seamless, efficient, and convenient for both students and administration.

---

## 💡 Features

- **Student Registration:** Students can sign up and provide details required for bus pass generation.
- **Bus Fee Verification:** Integration to verify whether the student has paid the required fees.
- **Digital Bus Pass Generation:** A unique pass is generated for each student, downloadable in a portable format.
- **Admin Panel:** Administrators can manage student records, approve registrations, and update pass details.

## 🚀 How to Use

1. Clone this repository:  
   ```bash
   git clone https://github.com/adarshmadhusoodanan/Mini-Project.git
   cd Mini-Project
   ```
2. Set up the database:
   - Create a MySQL database and import the provided schema.
3. Configure the environment:
   - Update the `config.py` file with your database credentials.
4. Start the Flask application:
   ```bash
   flask run
   ```
5. Access the application on your local server.
